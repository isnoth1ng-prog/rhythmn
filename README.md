# Rhythm

Rhythm — iOS-приложение для поиска и прослушивания музыки с библиотекой, плеером, текстами песен, рекомендациями и собственной темой. Владелец не программирует и не имеет Mac; реализацию ведёт Codex, сборки идут через GitHub Actions.

В репозитории уже есть ранний SwiftUI-прототип с демо-данными и workflow для сборки iOS Simulator. Демо-каталог не ищет реальные песни и не воспроизводит звук.

- Требования продукта: docs/PRODUCT_SPEC.md
- Сборка и будущая публикация: docs/BUILD_AND_RELEASE.md
- План: docs/WORK_PLAN.md

Держим задачи небольшими. Не меняем старый isnoth1ng-prog/rhythm. Не извлекаем звук и не обходим удаления или ограничения провайдеров. При необходимости работу можно передать Gemini или Claude 4.6.

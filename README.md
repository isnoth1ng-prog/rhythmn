# 🎵 Rhythm — iOS Music Player (Apple Music & Яндекс Музыка)

Полнофункциональное iOS-приложение для прослушивания музыки со стильным интерфейсом в стиле Apple Music и Яндекс Музыка.

## ✨ Возможности
* 🏠 **Главная** — чарты, новинки, персональные рекомендации.
* 🔍 **Поиск** — живой поиск по трекам и артистам с дебаунсом.
* 👤 **Артист** — страница артиста с топ-треками и дискографией альбомов.
* 📚 **Библиотека** — сохранённые треки в локальной памяти (❤️), кнопка «Перемешать всё».
* 🌊 **Моя Волна** — бесконечный умный поток рекомендаций, подбирающийся на лету.
* 🎶 **Плеер** — Mini Player над таб-баром и полноэкранный Full Player с dynamic blur фоном.
* 🎤 **Анимированный караоке-текст** — inline-текст песен (LRCLIB synced lyrics) как в Apple Music: активная строка увеличивается и светится, тап по строке перематывает трек.
* ⚙️ **Настройка сервера** — прямо в приложении (иконка ⚙️ на Главной) можно указать IP/домен вашего бэкенда.

## 📲 Установка через Sideloadly (без платного аккаунта Apple Developer)

1. Откройте вкладку **[Actions](../../actions)** в этом репозитории.
2. Выберите последний успешный запуск workflow **Build iOS IPA (Sideloadly)**.
3. Внизу страницы в блоке **Artifacts** скачайте **`Rhythm-IPA`** (распакуйте архив, внутри файл `Rhythm.ipa`).
4. Подключите iPhone к компьютеру кабелем и откройте **Sideloadly**:
   - Перетащите `Rhythm.ipa` в окно Sideloadly.
   - Введите ваш Apple ID (бесплатный).
   - Нажмите **Start**.
5. На iPhone перейдите в: **Настройки → Основные → VPN и управление устройством**, выберите ваш Apple ID и нажмите **«Доверять»**.

## 🖥️ Запуск Python Бэкенда

Приложение подключается к бэкенду на FastAPI для парсинга треков (YouTube Music + yt-dlp) и текстов (LRCLIB).

1. Перейдите в папку `backend`:
   ```bash
   cd backend
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8000
   ```
3. Если бэкенд запущен на вашем ПК, в приложении на iPhone нажмите ⚙️ на экране «Главная» и укажите локальный IP вашего компьютера (например: `http://192.168.1.100:8000/api`).

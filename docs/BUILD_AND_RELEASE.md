# Сборка iOS через GitHub Actions

## Что настроено

Workflow `.github/workflows/ios-build.yml` собирает приложение на macOS runner GitHub Actions при push в `main`, pull request или вручную через вкладку **Actions**. Исходный код и публикация при этом не требуют Mac у владельца.

После успешной сборки Actions прикрепит архив `Rhythm-Simulator.zip` на 14 дней. Внутри — сборка для iOS Simulator, чтобы проверять результат в CI. Это **не IPA и не устанавливаемая на iPhone сборка**.

## Что потребуется для установки на iPhone и публикации

Для распространения на реальных устройствах понадобится подпись приложения и provisioning profile из Apple Developer account. Apple Developer Program стоит $99 в год (или местная цена); она также открывает TestFlight и App Store distribution. Позже можно настроить безопасные GitHub Actions secrets и отдельный workflow для TestFlight. До этого этапа сертификаты/пароли в репозиторий добавлять нельзя.

## Dynamic Island

Приложение не может рисовать произвольные элементы за вырезом Dynamic Island. В интерфейсе будет собственный знак Rhythm под системной областью; системная Live Activity в Dynamic Island — отдельная функция, которую можно добавить позже для текущего трека.

## Как скачать результат CI

1. Открой вкладку **Actions** в репозитории.
2. Выбери успешный запуск **iOS build**.
3. Внизу страницы скачай artifact **rhythm-ios-simulator**.

Пока нет музыкального сервиса, установленной версии для iPhone и звука в прототипе. Сейчас CI нужен, чтобы собирать и сохранять проверяемую iOS-версию проекта на стороне GitHub.

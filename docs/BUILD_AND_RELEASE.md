# Сборка iOS и установка через Sideloadly

## Автоматическая сборка

Workflow `.github/workflows/ios-build.yml` собирает проект на macOS runner GitHub Actions при push в `main`, pull request или ручном запуске через вкладку **Actions**.

Каждый успешный запуск сохраняет два artifact на 14 дней:

- `rhythm-iphone-ipa` — unsigned IPA, который можно загрузить в Sideloadly для подписи и установки на iPhone.
- `rhythm-ios-simulator` — сборка для симулятора; она не устанавливается на iPhone.

## Установка

1. Открой вкладку **Actions** репозитория и выбери успешный workflow **iOS build**.
2. Скачай artifact **rhythm-iphone-ipa** и распакуй архив artifact, чтобы получить файл `Rhythm-unsigned.ipa`.
3. Открой Sideloadly на Windows, выбери устройство и перетащи IPA в окно приложения.
4. Войди с Apple ID в самом Sideloadly и начни установку. Не отправляй пароль Apple ID в этот чат или в GitHub.
5. На iPhone при необходимости включи Developer Mode и доверь профиль разработчика.

Sideloadly сообщает, что работает с бесплатными Apple ID; бесплатная подпись приложения действует 7 дней, после чего его нужно подписать/установить снова. У бесплатного аккаунта также есть ограничения на число одновременно установленных sideloaded-приложений. См. [официальный сайт](https://sideloadly.io/) и [FAQ](https://sideloadly.io/faq.html).

IPA собирается без подписи. Sideloadly подписывает его при установке. Подписанный IPA, TestFlight и App Store distribution — отдельные этапы.

## Важные ограничения текущей сборки

Прототип пока использует демо-треки: звука, живого музыкального поиска и настоящих текстов песен в нём нет. Установка IPA позволит проверить текущий интерфейс на iPhone, но не превращает демо-плеер в работающий музыкальный сервис.

YouTube Data API не разрешает извлекать отдельную аудиодорожку или использовать API-клиент для фонового воспроизведения. Поэтому в проект не добавляется yt-dlp для скачивания/отделения музыки из YouTube. Допустим только официальный YouTube-плеер в рамках его правил; для отдельного музыкального плеера надо выбрать каталог/API, который разрешает такое воспроизведение.

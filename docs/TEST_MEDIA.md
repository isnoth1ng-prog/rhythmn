# Test media

For the first prototype, use only a royalty-free or public-domain recording with a verifiable license. Record:
- track title and performer
- direct media URL
- source page
- license and required attribution
- date checked

For lyric UI testing, use public-domain lyrics (for example, a traditional folk song such as “Scarborough Fair”) and label them as sample lyrics. Do not copy lyrics from a copyrighted commercial recording. Do not imply sample audio is a licensed streaming catalog.

No real media has been bundled in this initial commit.

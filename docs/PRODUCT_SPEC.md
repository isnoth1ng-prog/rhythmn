# Rhythm — продукт и текущее состояние

## Продукт

Rhythm — нативное iOS-приложение на SwiftUI с темами, персональной библиотекой и единым плеером. Визуальная система использует крупную типографику, фирменные обложки-заполнители, системные материалы и выразительные акцентные цвета.

## Что реализовано

- Главный экран, поиск, «Моя волна», коллекция и настройки.
- Локальные избранные и сохранённые треки, история прослушивания и пользовательские плейлисты.
- Поиск каталога Apple Music через MusicKit при наличии разрешения; локальный демо-каталог остаётся fallback.
- Воспроизведение доступных Apple Music preview URL через AVPlayer, с обложками и метаданными каталога.
- Очередь, повтор, перемешивание, перемотка, фоновая аудиосессия и системные Now Playing команды.
- Live Activity / Dynamic Island для текущего состояния плеера при поддержке системы.
- Темы и акцентный цвет с локальным сохранением.
- «Моя волна» использует локальные лайки, историю и выбранное настроение; это локальная рекомендация, а не персонализация Apple Music.

## Ограничения

Полное воспроизведение композиций по подписке Apple Music пока не подключено. Приложение воспроизводит только preview-фрагменты, предоставленные MusicKit для конкретного результата. Для каталога владелец должен включить MusicKit для App ID в Apple Developer, а пользователь — разрешить доступ на устройстве. При отсутствии разрешения приложение запускается с локальным демо-каталогом.

Демо-исполнители, альбомы, тексты и треки остаются вымышленными UI-данными и не выдаются за реальные релизы. Сохранённые MusicKit результаты можно искать и воспроизводить в рамках доступного превью, но отдельные страницы альбомов и полные лицензированные тексты каталога не заявлены как готовые функции.

## Сборка и дистрибуция

Sources/Rhythm — приложение, Sources/RhythmWidget — расширение Live Activity. GitHub Actions собирает iPhone target, проверяет метаданные расширения и упаковывает неподписанный IPA для установки через Sideloadly. Фактический статус каждого запуска и его IPA-артефакт нужно смотреть в GitHub Actions.

Подробности MusicKit и необходимые настройки находятся в [MUSIC_SOURCE_INTEGRATION.md](MUSIC_SOURCE_INTEGRATION.md).

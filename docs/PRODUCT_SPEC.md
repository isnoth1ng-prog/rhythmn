# Rhythm — требования продукта

## Цель

iOS-приложение для поиска и прослушивания музыки с библиотекой, текстами, рекомендациями и оригинальным интерфейсом. Владелец не программирует, не имеет Mac и ожидает, что реализацию и настройку выполняет Codex. Сборка — через GitHub Actions.

## Функции

1. Моя музыка — библиотека сохранённых треков и недавняя история.
2. Поиск по названию и автору; чистые метаданные без дублей, ремиксов и мусорных названий там, где источник позволяет.
3. Плеер — обложка, название, кликабельный автор/дискография, прогресс и тайминг, перемотка, play/pause, предыдущий/следующий, добавление в библиотеку, тексты, повтор и shuffle.
4. Анимированные синхронизированные тексты песен в стилистике современных музыкальных плееров.
5. Моя волна — рекомендации по сохранениям, прослушиваниям и поиску.
6. Настройка тёмной матовой/стеклянной темы и акцентов. Оригинальный знак Rhythm под Dynamic Island; визуальные ориентиры — Apple Music, Liquid Glass, Tesla, Nothing.

## Музыка

Главное пожелание — версии без цензуры и чистые поля названия/автора, в том числе русскоязычная музыка и удалённые с крупных сервисов треки. Это цель, но не обещание до выбора доступного каталога. Нельзя обходить удаление, доступ, авторские права и условия провайдеров; нельзя извлекать звук из YouTube или парсить страницы в обход API.

SoundCloud API документирует поиск и потоковое воспроизведение публичных треков, доступных для off-platform streaming; встречаются состояния playable, preview и blocked, требуется атрибуция автора и SoundCloud. YouTube Data API даёт поиск видео и метаданные, но сам по себе не разрешает извлекать аудио как из независимого музыкального каталога. Наличие нужных несensored версий русскоязычных треков и права на них ещё не подтверждены. Заблокированные треки останутся недоступны.

Для отображения и синхронизации текстов понадобится источник с подходящими правами. Пока показывать только обозначенное демо или пустое состояние.

## Техническая основа

- Только iOS на первом этапе, нативный SwiftUI.
- Репозиторий — isnoth1ng-prog/rhythmn. Старый isnoth1ng-prog/rhythm не менять.
- XcodeGen генерирует Xcode project; GitHub Actions macOS runner собирает unsigned iOS Simulator artifact.
- Simulator artifact не устанавливается на iPhone. Установка/TestFlight требуют Apple signing assets; публикация требует Apple Developer Program.
- Dynamic Island — системная область: приложение не может рисовать под физическим вырезом. Сначала знак Rhythm размещается ниже неё; системную Live Activity можно добавить позже.
- Первый прототип использует вымышленные демо-треки, без звука и настоящих текстов.

## Этапы

1. SwiftUI интерфейс: библиотека, поиск, плеер, демо-тексты, страница автора, локальные рекомендации, акценты темы. Настроить CI.
2. Проверить API и покрытие каталогом русских треков; выбрать один источник только после подтверждения правил и доступности.
3. Реализовать реальное воспроизведение, статусы blocked/preview и атрибуцию согласно официальным правилам.
4. Подключить лицензированные тексты и настоящую дискографию.
5. Улучшать локальные рекомендации по поиску, сохранениям и прослушиваниям; оценить синхронизацию.
6. Настроить подпись, TestFlight и публикацию после Apple Developer enrollment.

# Музыкальные источники Rhythm

## Apple Music

MusicKitMusicSource использует MusicKit для поиска настоящих песен в каталоге Apple Music. Для результатов, у которых Apple предоставляет аудиопревью, Rhythm передаёт URL AVPlayer и показывает настоящую обложку и метаданные. Демо-каталог остаётся доступен, если разрешение или сервис MusicKit недоступны.

Первый поиск запрашивает у пользователя разрешение MusicKit. Для доступа к сервису MusicKit владелец приложения должен включить MusicKit для App ID в Apple Developer account. Это настройка подписи приложения; секретные ключи в репозиторий не добавляются. Пользователю также нужен интернет. Rhythm не выдаёт превью за полное воспроизведение трека: полноформатная подписная очередь через ApplicationMusicPlayer пока не подключена.

## Граница источника

- loadCatalog() отдаёт демонстрационные треки для первого запуска без запроса разрешений.
- searchCatalog(_:) ищет реальные песни в Apple Music после согласия пользователя.
- audioURL(for:) возвращает только официальный preview URL, если он доступен.
- lyrics(for:) не возвращает авторские тексты для каталожных треков, если источник их не предоставляет.
- Метаданные и ссылки превью из результатов кэшируются локально для библиотеки. Пользовательские лайки, списки и настройки по-прежнему хранятся на устройстве.

Если MusicKit не авторизован или недоступен, Rhythm показывает причину и локальную демо-коллекцию. Другие источники добавляются через протокол MusicSource без обращения к неподдерживаемым endpoint'ам.

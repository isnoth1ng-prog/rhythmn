# Подключение музыкального источника

Сейчас приложение использует DemoMusicSource: он отдаёт локальный каталог, но не предоставляет аудио. Реальный источник подключается через протокол MusicSource в Sources/Rhythm/MusicSource.swift.

## Контракт

- loadCatalog() возвращает очищенные метаданные: стабильный ID, название, исполнитель, альбом, длительность, теги и визуальный тон.
- audioURL(for:) возвращает URL потока для передачи в AVPlayer. Если вернёт nil, интерфейс останется в режиме без аудио и покажет сообщение.
- lyrics(for:) возвращает строки с временными метками. Плеер выделяет текущую строку и прокручивает текст.

RhythmAppModel отвечает за локальные лайки, библиотеку, плейлисты, историю, очередь и рекомендации. Источник отвечает за каталог и получение потока; UI не должен знать детали конкретного сервиса.

## Ограничение текущей сборки

Реальные API, ключи, авторизация, поиск в сети, обложки и потоковое аудио не подключены. В репозитории нет токенов и аудиофайлов. После выбора источника можно добавить отдельный адаптер, не переписывая экраны и библиотеку.

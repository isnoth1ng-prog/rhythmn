# Текущий план работы

Реализацию выполняет Codex. Владелец не программирует и не имеет Mac; сборки выполняются через GitHub Actions в isnoth1ng-prog/rhythmn. Старый репозиторий isnoth1ng-prog/rhythm не менять.

1. Создать SwiftUI-прототип с демо-данными и оригинальным векторным знаком.
2. Реализовать библиотеку, поиск, плеер, демо-тексты, страницу автора, волну и настройку акцента.
3. Добавить workflow для сборки iOS Simulator и загрузки artifact.
4. Проверить CI и исправить ошибки сборки.
5. Проверить легальные музыкальные каталоги и lyrics provider; не обещать uncensored версию без подтверждения.
6. Позже настроить Apple signing/TestFlight через защищённые GitHub Actions secrets.

Модель можно сменить на Gemini или Claude 4.6 между этапами; handoff должен включать точный статус и следующий шаг.
